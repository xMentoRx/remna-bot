📢 Настройка Админ-Чата & Форум-Топиков Алертов

Пошаговая инструкция интеграции мониторинга с вашей Супергруппой Telegram:

1️⃣ **Создайте Супергруппу** в Telegram и включите в её настройках «Темы» (Topics / Forums).

2️⃣ **Добавьте Вашего Бота** в группу и дайте права Администратора (Отправка сообщений, Управление темами).

3️⃣ **Создайте 3 Темы (Topics)**:

  • 🟢 **Топик #1**: Мониторинг Нод (ID топика, напр. 2)
  • 🚨 **Топик #2**: Алерты Слива Подписок (HWID) (ID топика, напр. 3)
  • 💾 **Топик #3**: Ежедневные Бэкапы БД (ID топика, напр. 4)

🚀 Развернуть Свежую Панель Remnawave

⚠️ ТРЕБОВАНИЕ ПЕРЕД ДЕПЛОЕМ (DNS A-ЗАПИСИ):
Зайдите в Cloudflare или к вашему регистратору и направьте 2 A-записи на IP вашего VPS:
• panel.domain.com (или pnl.domain.com) ➔ IP вашего VPS
• sub.domain.com (или subscription.domain.com) ➔ IP вашего VPS
(В Cloudflare ставьте ☁️ Серые облачка (DNS Only / Proxied: OFF)!)

🔌 Подключить Существующую Панель

📖 КАК ПОЛУЧИТЬ API ТОКЕН B REMNAWAVE:
1. Зайдите в вашу панель Remnawave ➔ ⚙️ Настройки ➔ 🔑 API Токены.
2. Нажмите «Создать токен» (Create Token).
3. Скопируйте длинный токен и вставьте его в поле ниже!
