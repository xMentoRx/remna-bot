## 🚀 Основные возможности

* 🌐 **Прямой встроенный прокси Remnawave UI (`/remna_embed`)**:
  Официальный веб-интерфейс Remnawave со всеми его родными вкладками (*Главная, Пользователи, Ноды, Профили, Хосты, Настройки*) транслируется прямо внутри Telegram MiniApp с авто-инъекцией панели управления **Remna-Bot Bar**.
* ⚖️ **Нативный Клиентский Балансировщик («🇪🇺 Автовыбор»)**:
  Автоматическое создание и привязка виртуального хоста балансировки со стратегией `leastLoad` и инъекцией `injectHosts`.
* 🚀 **1-Click Деплой Свежей Панели**:
  Автоматическое развертывание Docker Engine, PostgreSQL 16, Remnawave Backend и Caddy SSL на чистый VPS за 45 секунд с авто-регистрацией SuperAdmin.
* 🖥️ **1-Click Деплой Нод & Self-Steal Nginx**:
  Установка ноды Xray/Reality с созданием персонального VLESS-Reality профиля, маскировкой под реальный сайт через мемори-сокет `/dev/shm/nginx.sock` и включением ускорения BBRv3.
* ⚡ **Сетевой Ускоритель BBRv3 & ZRAM Cleaner**:
  Оптимизация параметров ядра `sysctl`, включение BBRv3 / XanMod и ZRAM с подсистемой детекции уже активного буста (без лишних перезагрузок VPS).
* 🚨 **Детектор расшаривания подписок (HWID / Multi-IP Leak Alerts)**:
  Автоматический фоновый сканер абуза лимита устройств и сессий с нескольких IP. При обнаружении слива отправляет тревожное сообщение в целевой топик супергруппы Telegram с кнопками быстрой блокировки `🚫 Заблокировать подписку` или `🔄 Сбросить трафик в 0`.
* 💾 **Ежедневный Авто-Бэкап PostgreSQL в Telegram**:
  Автоматическое создание дампов базы данных PostgreSQL раз в 24 часа и отправка сжатых `.sql.gz` архивов файлом в специальный топик Бэкапов (с поддержкой ручного запуска по кнопке в MiniApp).
* 🛡️ **SSH Hardening & Key Vault Suite**:
  Автоматическая генерация ключей `Ed25519`, смена SSH порта со стандартного 22 на безопасный **`5422`**, отключение парольного входа, защита от брутфорса `Fail2ban` и выдача скачиваемых файловых ключей `.pem` на Рабочий Стол/смартфон.
* 🔍 **Интеллектуальный поиск юзеров**:
  Поиск по Telegram ID, аккаунтам формата `user_123456789`, ссылкам `t.me/` и UUID с мульти-версионной адаптацией Remnawave v2.7.4+, v2.8+ & v3.0+.
* 🎨 **Динамические Темы Оформления**:
  Мгновенное переключение кастомных тем (*Cyberpunk, Emerald, Sunset, Midnight*) прямо поверх графиков Remnawave.
* ⚡ **Ookla 10Gbit Speedtest**:
  Интерактивное измерение параметров сети (Ping, Download, Upload) непосредственно в интерфейсе MiniApp.

## 📦 Быстрый старт (Установка за 1 минуту)

### 0️⃣ Предварительная подготовка (перед запуском)

1. **Создайте Telegram-бота через BotFather**:
   - Перейдите к [@BotFather](https://t.me/BotFather) в Telegram.
   - Отправьте команду `/newbot`, задайте имя и юзернейм для вашего бота.
   - Скопируйте и сохраните **Bot Token** (формата `1234567890:ABCdefGHIjklMNOpqrsTUVwxyZ`).

2. **Узнайте свой Telegram Admin ID**:
   - Откройте бота [@userinfobot](https://t.me/userinfobot) или [@raw_data_bot](https://t.me/raw_data_bot) и скопируйте ваш числовой ID (например `123456789`).

3. **Подготовьте чистый Linux VPS (Ubuntu / Debian)**:
   ```bash
   apt update && apt install -y curl nano git
   ```

---

### 🚀 Установка на VPS (в 1 команду)

Запустите автоматический инсталлятор на вашем VPS:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/xMentoRx/remna-bot/main/install.sh)
```

При первом запуске скрипт в интерактивном диалоге попросит вас ввести:
1. `Telegram Bot Token` (из @BotFather)
2. `Telegram Admin ID` (ваш числовой ID или несколько через запятую)

Скрипт автоматически сформирует `.env`, развернет Docker и запустит бота за пару секунд!

---

### Вариант 2: Запуск через Docker Compose (Вручную)

```bash
git clone https://github.com/xMentoRx/remna-bot.git
cd remna-bot
cp .env.example .env
# Заполните BOT_TOKEN и ADMIN_CHAT_IDS
nano .env
docker compose up -d --build
```

## 📱 Пошаговое руководство первого запуска и использования MiniApp

После первой установки бота на VPS в 1 клик вы отправляете боту команду `/start` и открываете **Remna-Bot MiniApp**. Далее процесс зависит от вашего сценария:

### 🅰️ Сценарий A: Установка свежей панели Remnawave с нуля (на голый VPS)

1. В главном меню MiniApp выберите **«🚀 1-Click Деплой Свежей Панели»**.
2. Введите параметры целевого VPS для Панели:
   - **IP-адрес VPS**: IP вашего нового сервера (Ubuntu / Debian).
   - **Root-пароль**: Пароль от сервера (или подключение по SSH ключу).
   - **Домен Панели**: Например `panel.mydomain.com` (A-запись должна указывать на IP этого VPS).
   - **Домен Подписок**: Например `sub.mydomain.com` (A-запись должна указывать на IP этого VPS).
   - *(Дополнительно)* Включите галочку **🛡️ Авто-харденинг SSH**.
3. Нажмите **«🚀 Запустить Деплой Панели»**:
   - Бот за 45 секунд установит Docker Engine, PostgreSQL 16, Remnawave Backend v3.1.0 и Caddy SSL.
   - Выпустит официальные SSL-сертификаты Let's Encrypt для обоих доменов.
   - Автоматически зарегистрирует учетную запись **SuperAdmin**, сгенерирует секреты `APP_SECRET` и выпустит Bearer API Token.
   - Применит SSH-харденинг (генерация `Ed25519` ключей, смена порта на `5422`, защита `Fail2ban`) и предоставит скачиваемый ключ `.pem`.
   - **Автоматически привяжет созданную панель к вашему боту!**

---

### 🅱️ Сценарий B: Привязка УЖЕ существующей панели Remnawave

1. В главном меню MiniApp выберите **«🔗 Привязать существующую панель»**.
2. Введите:
   - **URL Панели**: Полный адрес вашей панели (`https://panel.mydomain.com`).
   - **API Bearer Token**: Токен из настроек панели Remnawave (раздел API Tokens).
3. Нажмите **«Подключить»**:
   - Бот проверит соединение, определит версию панели (v2.7.4+, v2.8+, v3.0+ или v3.1.0) и переключит интерфейс в режим полного управления!

  - **Сетевой Буст BBRv3 & ZRAM**: Оптимизация параметров ядра `sysctl` и очистка оперативной памяти в 1 клик (с защитой от повторных перезагрузок, если буст уже активен).

## 📢 Пошаговая настройка Админ-Чата & Алертов в Telegram MiniApp

Вам больше **не нужно** редактировать `.env` файлы вручную! Бот запускается после ввода токена бота и вашего Telegram ID, а все алерты и топики настраиваются из удобного интерфейса **Telegram MiniApp**:

1. **Создайте Супергруппу** в Telegram для вашей команды/администраторов.
2. В настройках группы включите переключатель **«Темы» (Topics / Forums)**.
3. **Добавьте бота** в группу и дайте ему права **Администратора** (*Отправка сообщений, Управление темами*).
4. **Создайте 3 Темы (Topics)** в группе:
   - 🟢 **Топик №1**: *Мониторинг Нод* (например `ALERT_TOPIC_ID = 2`)
   - 🚨 **Топик №2**: *Алерты Слива Подписок / HWID* (например `SHARING_ALERT_TOPIC_ID = 3`)
   - 💾 **Топик №3**: *Ежедневные Бэкапы Базы Данных* (например `BACKUP_ALERT_TOPIC_ID = 4`)
5. Откройте **Remna-Bot MiniApp** ➔ перейдите на вкладку **🎨 Стиль & Настройки**:
   - Впишите ID Супергруппы (начинается с `-100...`)
   - Впишите ID топика нод, топика слива подписок и топика бэкапов
   - Нажмите **💾 Сохранить Настройки Админ-Чата** и **🧪 Проверить Связь**. Бот мгновенно пришлет проверочные алерты во все назначенные топики!

## 🛠️ Переменные окружения (`.env`)

| Переменная | Описание | Обязательная |
| :--- | :--- | :---: |
| `BOT_TOKEN` | Токен Telegram-бота из @BotFather | **Да** |
| `ADMIN_CHAT_IDS` | Telegram ID администраторов через запятую (`12345678,9876543`) | **Да** |
| `ALERT_CHAT_ID` | ID супергруппы для отправки уведомлений и алертов | Нет |
| `ALERT_TOPIC_ID` | ID форума/топика супергруппы под алерты состояния нод (по умолчанию 0) | Нет |
| `SHARING_ALERT_TOPIC_ID` | ID форума/топика под алерты расшаривания подписок / HWID слива | Нет |
| `BACKUP_ALERT_TOPIC_ID` | ID форума/топика под ежедневные файловые бэкапы PostgreSQL | Нет |
| `API_URL` | Стартовый URL панели Remnawave (`https://panel.mydomain.com`) | Нет |
| `API_TOKEN` | Стартовый API Bearer Token | Нет |
| `WEBAPP_PORT` | Порт сервера MiniApp (по умолчанию `8080`) | Нет |

## 🔒 Безопасность и Гарантии

* **Fail-safe проверка входа по ключу**: Бот сначала проверяет авторизацию по созданному ключу SSH, и лишь при 100% успехе отключает вход по паролю.
* **DevOps Non-Interactive Suite**: Все системные команды оснащены флагами `DEBIAN_FRONTEND=noninteractive` и `NEEDRESTART_MODE=a`, гарантируя отсутствие зависаний на терминальных запросах `Enter/Y/N`.
